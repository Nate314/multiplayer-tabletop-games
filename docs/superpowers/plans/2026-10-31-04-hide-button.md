# Hide Button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Hide / Show button in every game header that, on this browser only, makes everything below the header unreadable and unusable until it is pressed again.

**Architecture:** `GameView` holds a `hidden` boolean in React state and sets `data-hidden` on `.game-root`. One rule in `src/App.scss`, outside `:where()`, gives every direct child of a hidden `.game-root` except the header, the cover and the History dialog `visibility: hidden`, the same child-selector pattern as the existing `[data-awaiting-agreement]` dimming. The game screen stays mounted (a rack order, a selection or the Jenga scene survive), but nothing in it can be seen, clicked, tabbed to or found with find-in-page. A `.hidden-cover` banner says the game is hidden. Nothing is sent to the server.

**Tech Stack:** React 19, TypeScript 5.9, SCSS, node:test, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-31-pause-resume-jenga-and-fixes-design.md`, section 4. Index plan: `docs/superpowers/plans/2026-10-31-pause-resume-jenga-and-fixes.md` (Shared contracts, ports, Global Constraints, Combining). Branch `hide-button` from `pause-resume-jenga-and-fixes`. Server PORT 3204, E2E_PORT_BASE 6470.

## Global Constraints

All of the index plan's Global Constraints, plus:

- The button is `src/components/HideButton.tsx`, class `hide-button`, an icon button like Settings: `aria-label` and `title` are `Hide` while the game shows and `Show` while it is hidden. Icons are server SVGs `icon/eye-off` (shown while visible, the action is to hide) and `icon/eye` (shown while hidden), drawn with `lineIcon` in `shared/svg/icons.ts`.
- Header order: Back to games, title, History, Share, Rules, **Hide**, Settings, GitHub link, theme toggle. Hide goes directly before `<SettingsButton>` in `GameView.tsx`; nothing else in the header moves (index plan, Header buttons).
- Shown to every player, every pass-and-play device and every spectator. Not shown on a table screen (it never holds anything private, and it is in view of everyone anyway).
- The hidden state is React state in `GameView` only: not stored, not sent, reset by Back to games or a reload.
- The cover copy, exactly: heading `Game hidden`, text `Press the eye button above to show it again.` It is `<section className="hidden-cover" aria-label="Game hidden">`.
- The hide rule, exactly, in `src/App.scss` next to the `[data-awaiting-agreement]` rule: `[data-game][data-hidden] > :not(.game-header, .hidden-cover, .history-overlay) { visibility: hidden; }`.
- Phones (480 px or less): Hide moves up to the title row, right of the title, so Back to games, History, Rules and Settings keep their one row (the existing `e2e/settings.spec.ts` phone test). Rules outside `:where()` so Azul's and Quoridor's own header rules cannot undo it.
- Rulings (state them in the PR's Rulings):
  - Everything below the header is covered, not only the private parts. The spec allows this, and per-game masking cannot be trusted: a `HistoryBoard` with `viewer` `null` still draws seat-only fields when given a seat's view (Pictionary's chat holds the seat-addressed lines), so it is not a safe "public table".
  - `visibility: hidden` rather than unmounting or `display: none`: local screen state survives, and the Jenga canvas keeps its size. Hidden elements cannot be clicked, focused or read by a screen reader.
  - History stays usable while hidden: the live History dialog shows only table views (`viewer` `null`), so it holds nothing private.
  - Hidden survives a pass-and-play handoff. The Pass the device bar is covered too, so the next player presses Show.
- Contract additions: class `hide-button`, attribute `data-hidden` on `.game-root`, class `hidden-cover`, icons `icon/eye` and `icon/eye-off`. Plans 7 and 9: a dialog or prompt rendered as a direct child of `.game-root` is hidden with the game; one rendered inside the header (as Rules and Settings do) is not.

## Review Focus

1. Something private rendered outside the covered children (a drag ghost, a fixed overlay, a portal) stays readable while hidden. The drag ghost is appended to `[data-game]`, so it is a covered child; Task 1's test asserts that no visible element is left below the header in Uno with a hand dealt.
2. An element inside the game with its own `visibility: visible` would show through. None exists today (only Rummikub sets `visibility: hidden`); Task 1 adds a grep step so a reviewer sees the check.
3. Keyboard handlers on `window` still fire while hidden. Today only Quoridor's wall rotation listens on `window`, and it changes only the local selection, sending nothing. Task 1's test presses Tab through the page and asserts focus never lands below the header.
4. The phone header at 320 px in a game with its own header CSS (Azul, Quoridor, Dominoes): Hide wraps to its own row or overlaps the title. Task 2's test runs over every game at 390 and 320 px.
5. A game theme that colors `.settings-button` but not `.hide-button`, so Hide looks like a stray default button in Uno, Hearts and the others. Task 2 adds `.hide-button` to each of those lists and its test compares Hide's background to Settings' in every game.

- [ ] **Step 6: Write the failing e2e tests** in `e2e/hide.spec.ts`. Helpers: `const hideButton = (page: Page) => page.locator('.game-header').getByRole('button', { name: 'Hide', exact: true })`, the same for `Show`, and `const below = (page: Page) => page.locator('.game-root > :not(.game-header, .hidden-cover) :visible')`.

```ts
test('Hide covers the hand and everything below the header, and Show brings it back', async ({ seat }) => {
  const { pages: [alice, bob] } = await seat('uno', ['Alice', 'Bob']);
  const hand = alice.locator('.hand-cards');
  await expect(hand.getByRole('button')).toHaveCount(7);
  await hand.evaluate(element => { element.setAttribute('data-test-mark', ''); }); // proves no remount
  await hideButton(alice).click();
  await expect(alice.locator('.game-root')).toHaveAttribute('data-hidden', '');
  await expect(hand).toBeHidden();
  await expect(below(alice)).toHaveCount(0);
  await expect(alice.getByRole('region', { name: 'Game hidden' })).toContainText('Press the eye button above to show it again.');
  await expect(bob.locator('.hand-cards')).toBeVisible(); // only Alice's screen
  await showButton(alice).click();
  await expect(alice.locator('.game-root')).not.toHaveAttribute('data-hidden');
  await expect(alice.locator('.hand-cards[data-test-mark]')).toBeVisible();
  await expect(alice.getByRole('region', { name: 'Game hidden' })).toHaveCount(0);
});

test('while hidden nothing can be clicked or reached with Tab', async ({ seat }) => {
  const { pages: [alice] } = await seat('connectfour', ['Alice', 'Bob']);
  await hideButton(alice).click();
  await expect(alice.getByRole('button', { name: 'Drop in column 1' })).toBeHidden();
  for (let i = 0; i < 15; i++) {
    await alice.keyboard.press('Tab');
    expect(await alice.evaluate(() => Boolean(document.activeElement?.closest('.game-root > :not(.game-header)')))).toBe(false);
  }
  await showButton(alice).click();
  await alice.getByRole('button', { name: 'Drop in column 1' }).click(); // the screen works again
});

test('hiding and showing sends nothing to the server', async ({ seat }) => {
  const { pages: [alice] } = await seat('connectfour', ['Alice', 'Bob']);
  const sent: string[] = [];
  alice.on('websocket', socket => socket.on('framesent', frame => sent.push(String(frame.payload))));
  await alice.reload();
  await expect(hideButton(alice)).toBeVisible();
  await alice.waitForTimeout(500); // the rejoin's own messages
  const before = sent.length;
  await hideButton(alice).click();
  await showButton(alice).click();
  await alice.waitForTimeout(500);
  expect(sent.length).toBe(before);
});

test('a spectator can hide, a table screen has no Hide', async ({ seat, browser, server }) => {
  const table = await seat('hearts', ['Alice', 'Bob', 'Cara', 'Dan']);
  const dana = await watch(browser, server, 'hearts', table.gameId, 'Dana');
  await hideButton(dana).click();
  await expect(below(dana)).toHaveCount(0);
  const tv = await tableScreen(table);
  await expect(tv.locator('.hide-button')).toHaveCount(0);
});

test('History still opens while hidden', async ({ seat }) => {
  const { pages: [alice] } = await seat('connectfour', ['Alice', 'Bob']);
  await alice.getByRole('button', { name: 'Drop in column 1' }).click();
  await hideButton(alice).click();
  await alice.getByRole('button', { name: 'History' }).click();
  await expect(alice.getByRole('dialog', { name: 'History' })).toBeVisible();
});
```
