**Goal:** Add Tic-Tac-Toe (`tictactoe`) and Ultimate Tic-Tac-Toe (`ultimatetictactoe`), two-player Classic board games that share win-line checking and the X/O seat logic through modules inside `games/tictactoe/`.

**Architecture:** Two game folders on the existing `GameDefinition` contract, modeled on `games/connectfour/` (board in state, `shared/drawOffer.ts` for resign and draw offers, vote undo, the platform's "remaining player wins" on leave). `games/tictactoe/lines.ts` (the eight lines, cell names) and `games/tictactoe/marks.ts` (which seat plays X) are imported by both games' rules; `games/tictactoe/client/` holds the `Mark`, `Grid` and `GameStatus` components and an SCSS mixin that the Ultimate client also imports. **Tech Stack:** React 19, TypeScript 5.9, SCSS, node:test, Playwright.

## Global Constraints

- Players exactly 2 for both games (`minPlayers: 2`, `maxPlayers: 2`), category `'classic'`, no house rules.
- X always moves first. Game 1 of a room: seat 1 plays X. Each rematch swaps marks: `xSeat` is seat 1 when `gameNumber` (missing means 1) is odd, seat 2 when even. Both games (my call for Ultimate).
- Rules from Wikipedia ([Tic-tac-toe](https://en.wikipedia.org/wiki/Tic-tac-toe), [Ultimate tic-tac-toe](https://en.wikipedia.org/wiki/Ultimate_tic-tac-toe)); every difference listed under "Differences from Wikipedia" in each README, in the format of `games/connectfour/README.md`.
- Every move undoable by vote (platform). Resign and draw offers are the shared `EndingAction`s, as in Connect Four. A dismissed player loses: the platform's "X wins! Everyone else left." covers it.
- `games/ultimatetictactoe/` may import from `games/tictactoe/` (non-client files from rules, `client/` files from its client). Nothing in `games/tictactoe/` imports from `games/ultimatetictactoe/`. No client file imports server code beyond the game's own `rules.ts`, `lines.ts`, `marks.ts`, `types.ts`.
- SCSS nested under `[data-game="tictactoe"]` / `[data-game="ultimatetictactoe"]`, light and dark themes as in `connectfour.scss`.
- Files outside the two game folders, one line or list entry each: `games/registry.ts`, `games/infos.ts`, `src/clientGames.ts`, `shared/svg/gameIcons.ts` (the landing icon, required by `src/games/loadClientGame.test.ts`), `shared/categories.test.ts` (classic list), `games/standings.test.ts` (`FALLBACK_GAMES`), `e2e/landing.spec.ts` (the 33 card counts become 35), `README.md` (first sentence count and two-player list, game list), `docs/architecture.md` (the `shared/drawOffer.ts` line naming its games), plus `e2e/tictactoe.spec.ts` and `e2e/ultimatetictactoe.spec.ts`. Nothing else in `src/`, `server/`, `shared/` or `e2e/fixtures.ts`; if more seems needed, stop and report.
- No new npm dependency. No em-dashes in READMEs, FAQs, comments or commit messages.
- `npm test`, `npm run typecheck`, `npm run lint` and both e2e specs pass.

## Review Focus

1. Ultimate: a player sent to a board that is won but still has empty cells must get a free choice among open boards, and must still not be able to mark that won board (Task 4 test `'a won board takes no more marks, even on a free choice'`).
2. A final mark that both completes a line and fills the last cell (Tic-Tac-Toe) or decides the last open board (Ultimate) must be a win, not a draw (Task 2 and Task 4 tests).
3. Rematch: in game 2 seat 2 is X and moves first; an approved undo of game 2's first move gives the turn back to seat 2, not seat 1 (Task 2 manager test `'a rematch swaps the marks and undo keeps them'`).
4. Untrusted payloads such as `cell: '4'`, `4.5`, `-1`, `9`, a missing `board`, or `type: 'drop'` are refused with an error and leave the state unchanged (Task 2 and Task 4 tests).
5. Ultimate at 320 px wide: 81 cells must fit without sideways scrolling and stay tappable (Task 5 e2e `'the big board fits a 320 px phone with tappable cells'`: no horizontal overflow, each cell at least 28 px).
