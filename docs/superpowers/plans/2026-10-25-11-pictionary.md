# Pictionary Implementation Plan (changeset 11)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Pictionary: one player draws a word they picked, everyone else guesses in a chat beside the live drawing, scored by speed, for 2 to 10 players.

**Architecture:** A new game folder `games/pictionary/` on the existing `GameDefinition` contract. Turn changes, scoring guesses and turn ends are on the timeline; strokes and chat are actions. The platform gains one small hook, `recordsAction`, so a correct guess (sent as a chat action, since the client cannot know it is correct) is recorded as a move. The word list lives in a server-only module that no client file imports, and `toPublicState` hides the word, the choices and the guessed-only chat from anyone who has not guessed.

**Tech Stack:** React 19, TypeScript 5.9, SCSS, Canvas 2D with Pointer Events, node:test, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-spectators-social-and-new-games-design.md`, feature 11. Index plan: `docs/superpowers/plans/2026-10-25-spectators-social-and-new-games.md`.

**Branch:** `pictionary`, wave 1, from master. PORT 3111, E2E_PORT_BASE 6310.

## Global Constraints

All of the index plan's Global Constraints, plus:

- `games/pictionary/words.ts` is imported only by `games/pictionary/rules.ts`. No file under `games/pictionary/client/` imports `rules.ts` or `words.ts`; shared client/server helpers go in `games/pictionary/clock.ts` or `games/pictionary/text.ts`, which import neither.
- A seat that has not guessed the current word (and is not the drawer) never receives the word, the word choices, the deck, a "So close!" line of another player, or a guessed-only chat line, in any view, `lastMove`, `gameStatus` or history step.
- House rules (exact values): `turnSeconds` 30, 60, **90** (standard), 120, 180; `wordChoices` **3** (standard), 4, 5; `drawsPerPlayer` 1, 2, **3** (standard), 4, 5. Players 2 to 10.
- Fixed timings: choosing a word 20 s (then a random choice is made for the drawer), the reveal pause 5 s. No timer runs in the lobby.
- Scoring: a correct guesser scores `10 + Math.round(90 * msLeft / turnMs)` (10 to 100); the drawer scores 25 per correct guesser.
- Category: a new `party` category, "Party games", after `strategy`. Jenga (plan 12) uses the same id.
- Pass-and-play is not offered for Pictionary (see Integration after wave 1).

## Review Focus

1. A guesser opens History mid-turn, or watches the raw WebSocket frames, and sees the word: the history (viewer `null`) view hides the word until the reveal, and an e2e test reads every frame a guesser receives (Task 3, Task 7).
2. A guess like "is it castle?" or "Castle " or "ice-cream" for "ice cream" is shown in the public chat and gives the word away: matching normalizes case, spaces and hyphens, and any message containing the normalized word as a whole word counts as correct, so "catapult" does not match "cat" (Task 3; add a test for exactly that).
3. The drawer disconnects or is dismissed mid-turn, or the last guesser leaves: the turn still ends (timer, or `onPlayerLeft` ends it at once) and the game never sticks (Task 2).
4. A long drawing grows the state without limit, and every action rewrites it in SQLite and broadcasts it: the per-turn point cap (20000 coordinates) and the 100 ms client batching keep it bounded; strokes are cleared each turn (Task 4).
5. A server restart mid-turn: `resumeClock` restarts the current phase with full time, so a room never times out at once on load (Task 2).

  type Tool = 'pen' | 'eraser';
  type Stroke =

    | { type: 'choose'; playerNumber: Seat }
    | { type: 'guess'; playerNumber: Seat; points: number }
    | { type: 'reveal'; word: string; reason: 'allGuessed' | 'timeUp' | 'drawerLeft' }
    | { type: 'nextTurn'; playerNumber: Seat }
    | { type: 'autoChoose'; playerNumber: Seat };
  type GameState = BaseGameState & {
    phase: Phase; deck: string[]; wordChoices: string[]; word: string | null;
    phaseStartedAt: number | null; // server ms; null in the lobby
    strokes: Stroke[]; nextStrokeId: number; guessed: Seat[]; // in guessing order
    scores: Record<Seat, number>; draws: Record<Seat, number>; // turns drawn so far
    chat: ChatLine[]; nextChatId: number; lastMove: LastMove | null;

    mask: string;            // the word with every letter as '_', spaces and hyphens kept
    word: string | null;     // only to the drawer, a seat in `guessed`, and everyone during the reveal or game over
    wordChoices: string[];   // only to the drawer while choosing

- Produces (`text.ts`, imported by client and server): `normalize(text: string): string` (lowercase, remove spaces, hyphens and apostrophes), `maskOf(word: string): string`, `isCorrect(guess, word): boolean` (normalized guess includes normalized word), `isClose(guess, word): boolean` (Levenshtein distance exactly 1 between normalized forms, not correct).
- Produces (`rules.ts`): `createGameState`, `resetLobby`, `applyMove`, `applyAction` (Task 3 and 4 fill it), `recordsAction`, `deadline`, `onDeadline`, `resumeClock`, `onPlayerLeft`, `toPublicState` (Task 3), `guesserPoints(msLeft: number, turnMs: number): number`, `DRAWER_POINTS = 25`.

Turn flow decisions:
- `resetLobby` shuffles `WORDS` into `deck` and deals `wordChoices` to seat 1 (`currentPlayer`), `phase: 'choosing'`, `phaseStartedAt: null`. The deck refills by reshuffling `WORDS` minus words already used when it runs short.
- Move `{ type: 'choose', index: number }` by the drawer while choosing: sets `word`, empties `wordChoices`, `phase: 'drawing'`, `phaseStartedAt: now`, clears `strokes` and `guessed`. This is the first move, so it starts the game.
- `deadline`: null when not started or game over; else `phaseStartedAt + phaseMs` (choosing 20 s, drawing `turnSeconds`, reveal 5 s).
- `onDeadline`: choosing picks `wordChoices[floor(random * length)]` (`autoChoose`); drawing reveals with `timeUp`; reveal starts the next turn.
- A correct guess that leaves every active non-drawer seat in `guessed` reveals with `allGuessed`.
- Reveal: `phase: 'reveal'`, `draws[drawer] += 1`, a system chat line "The word was <word>" (audience all), `gameStatus` "The word was <word>". `word` stays set until the next turn.
- Next turn: the next active seat after the drawer (`nextActivePlayer`) that has fewer than `drawsPerPlayer` draws; when none has, the game ends: `isGameOver`, `winners` the top scores, status "<names> won with <n> points".
- `resumeClock(state, now)`: started and not over sets `phaseStartedAt: now` (full time, like Scrabble).
- `onPlayerLeft`: the drawer leaving reveals with `drawerLeft`; a guesser leaving reveals with `allGuessed` when everyone left has guessed and at least one has.
- `recordsAction(state, seat, action)`: true only for a `chat` action from a non-drawer seat not yet in `guessed`, during `drawing`, whose text `isCorrect`.

### Task 6: History

**Files:**
- Create: `games/pictionary/client/HistoryBoard.tsx`, `games/pictionary/client/describeMove.ts`
- Test: `games/pictionary/client/describeMove.test.ts`

**Decision:** History steps are the timeline moves: a word chosen, each scoring guess, the reveal and the next turn. Each board shows the drawing as of that step (the reveal step holds the finished drawing, since strokes stay until the next word is chosen), the blanks or, from the reveal on, the word, the list of who guessed with their points, and the scores. No chat. `viewer` is used only through the view the server built, so a guesser's own file view hides the word until they guessed.

**Interfaces:**
- Produces `describeMove(state: PublicGameState): string`:
