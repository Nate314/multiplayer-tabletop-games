# Azul Drag and Drop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drag a tile from a factory or the center onto a pattern line or the floor; clicking still works.

**Architecture:** Use `useDrag` from `src/drag/useDrag.ts` as the other drag games do (read one, for example Quoridor's or Dominoes' `GameScreen.tsx`). Drag ids encode the source and color; drop targets are the pattern lines and floor of the player's own board. Lifting selects the tiles (so the existing highlight shows legal lines); a drop places them.

**Tech Stack:** React 19, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-assets-rules-loading-polish-design.md` (changeset 8). Read the index plan for Global Constraints, ports (PORT 3108, E2E_PORT_BASE 6250) and delivery.

## Review Focus (this changeset)

- Dropping on a line that cannot take that color (full, or a color already on the wall row) does nothing and returns the tiles; the selection stays so a click can finish (Task 1).
- Dragging when it is not your turn does nothing (no source props) (Task 1).
- A drag released over another player's board is a cancel (Task 1).
- Touch: a short tap still selects (the drag threshold), and the page does not scroll while dragging (shared hook behavior, browser check).

### Task 1: Drag sources and drop targets

**Files:** Create `games/azul/client/drag.ts` (pure id helpers); modify `games/azul/client/GameScreen.tsx`, `Factories.tsx`, `PlayerBoard.tsx`, `azul.scss`; test `games/azul/client/drag.test.ts`, `e2e/azul.spec.ts`; update `games/azul/README.md` controls and `docs/architecture.md` (drag games list).

**Interfaces:**
- `dragId(selection: Selection): string` (for example `factory-2-blue`, `center-red`) and `parseDragId(id: string): Selection | null`; drop targets `line-<row>` and `floor`, with `parseDropTarget(target: string): number | 'floor' | null`.
- `canLift(id)`: my turn, and the source has tiles of that color. `onLift(id)`: `setSelection(parseDragId(id))`. `canDrop(id, target)`: the target is on my board and the line accepts that color (reuse whatever function currently decides the highlighted lines; if it lives in `PlayerBoard.tsx`, move it into a pure function in `drag.ts` or `selection.ts` and test it). `onDrop`: `gameService.makeMove({ ...selection, line })`. `onCancel`: keep the selection.
- Every tile of that color in the source spreads `drag.source(id)`; my pattern lines and floor carry `data-drop`; `drag.over` adds a hover class.
