# Tri-Tiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Tri-Tiles (`tritiles`), a triangle-tile matching game in the style of Triominoes, for 2 to 6 players.

**Architecture:** A new game module `games/tritiles/` built like `games/dominoes/`: pure triangle-grid geometry and scoring modules, a rules module implementing `GameDefinition` (`shared/gameDefinition.ts`), and a lazy-loaded client. Rounds use the shared Continue step (`shared/rounds.ts`), hidden state uses `seatFields` (`shared/spectators.ts`), and the board zooms with the Jigsaw `keepCentre` helper, moved to `shared/`.

**Tech Stack:** TypeScript, React, SCSS, `node --test`, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-tri-tiles-design.md`

## Global Constraints

- Display name "Tri-Tiles", id `tritiles`, category `tile`, 2 to 6 players. No trademarked names or art.
- 56 tiles: corner numbers 0 to 5, each combination with repetition once, corners read clockwise in non-descending order from the lowest (Wikipedia: tiles whose numbers descend clockwise are omitted). Tiles rotate, never flip.
- Deal: 9 tiles each with 2 players, 7 with 3 or 4, 6 with 5 or 6. The rest is the hidden pool.
- Opening, every round: the highest triple held leads (5-5-5 first) and scores its sum plus 10; 0-0-0 scores 40. With no triple, the highest-sum tile leads and scores its sum only.
- A placed tile scores its sum. Hexagon +50 (two hexagons in one move +100). Bridge +40.
- Drawing: 5 points per tile drawn, at most 3 draws a turn. A drawn tile that fits may be played at once. After 3 draws with nothing playable, the player passes and loses another 10 (25 in all, matching Wikipedia). Empty pool and nothing playable: pass and lose 10.
- Going out: +25 plus the sum left in every other hand. Blocked round: the lowest hand scores the difference to each other hand; a tie for lowest scores nothing (as in Dominoes).
- House rules (`games/tritiles/options.ts`): `hexagon` toggle (standard true, label "Hexagon bonus"), `bridge` toggle (standard true, label "Bridge bonus"), `targetScore` choice 200 / 400 (standard) / 600.
- The target is checked only when a round ends; if several players pass it, the highest total wins and equal totals share the win.
- No new npm dependencies. No em-dashes in README, FAQ or commits.

**Differences from Wikipedia (for the README):** the bonuses and target are house rules; the game ends in the round someone reaches the target (Wikipedia plays one final round after that); a tie for lowest in a blocked round scores nothing; Wikipedia's bridge bonus also counts "adding a tile to" a bridge, here only completing one counts.

## Review Focus

- A tile that matches along an edge but clashes at a far point-only corner must be refused (Task 1 test `a point-only clash refuses the placement`).
- A placement that completes two hexagons at once scores +100, not +50 (Task 2 test).
- The draw count resets each turn, and a 4th draw in one turn is refused (Task 3 test `a fourth draw in one turn is refused`).
- A dismissed player's tiles return to the pool and the round can still end blocked (Task 3 test).
- An undo of a draw does not reveal the next pool tile (Task 3 test `undo reshuffles the pool`).

### Task 1: Tiles and triangle-grid geometry

**Files:**
- Create: `games/tritiles/tiles.ts`, `games/tritiles/grid.ts`
- Test: `games/tritiles/tiles.test.ts`, `games/tritiles/grid.test.ts`

**Interfaces:**
- Produces in `tiles.ts`: `TILES: readonly [number, number, number][]` (index is the tile id, 56 entries); `tileSum(tile: number): number`; `isTriple(tile: number): boolean`.
- Produces in `grid.ts`:
  - `type Cell = { x: number; y: number; up: boolean }` (a triangle; up and down triangles alternate).
  - `type Placed = { tile: number; cell: Cell; corners: [number, number, number] }` (numbers as laid, clockwise from the cell's first vertex).
  - `type Board = Placed[]`.
  - `cellKey(cell: Cell): string`, `verticesOf(cell: Cell): [string, string, string]` (vertex keys, clockwise), `edgeNeighbours(cell: Cell): Cell[]` (3), `pointNeighbours(cell: Cell): Cell[]` (the 9 that share only a vertex).
  - `rotations(tile: number): [number, number, number][]` (the 3 clockwise rotations, duplicates removed for triples and doubles).
  - `fits(board: Board, cell: Cell, corners: [number, number, number]): boolean`: cell empty, shares at least one edge with a placed tile (the empty board accepts any cell), and every vertex already numbered by any placed tile has the same number.
  - `openPlacements(board: Board, tile: number): { cell: Cell; corners: [number, number, number] }[]`: every fitting cell and rotation; on the empty board, one placement at `{ x: 0, y: 0, up: true }` per rotation.
  - `hexagonsCompleted(board: Board, cell: Cell): number`: vertices of `cell` around which all six triangles are filled once it is placed (0, 1 or 2).
  - `isBridge(board: Board, cell: Cell): boolean`: the new tile shares exactly one edge with placed tiles and the vertex opposite that edge is already numbered by a tile that does not share an edge with it.
